TOM & EAINDRA  -  AI chat friends for Windows 10/11 (chat only - for children)
=========================================================

Everything is inside this folder. Nothing else to install (no Node.js, no Python needed).

START
1. Unzip the whole folder somewhere, e.g.  C:\Tom-Eaindra   (do NOT run it from inside the zip).
2. Double-click  Tom-Eaindra.exe
   If Windows says "Windows protected your PC":  click "More info"  ->  "Run anyway".
3. (optional) Double-click  "Create Desktop Shortcut.cmd"  for a desktop icon.
   The buddies also start by themselves when Windows starts (turn off in Settings).

FIRST TIME: add a free AI key
4. Settings open by themselves. Get a FREE Google Gemini key at  https://aistudio.google.com/apikey
5. Settings -> AI providers -> Google Gemini -> Edit -> paste the key -> Test -> "Save provider" -> Save.
   (Keys are stored encrypted on this PC only.)

USE
- Click the character            = open / close the chat
- Drag the character             = move it
- Right-click it  or Ctrl+Alt+S  = Settings (switch Tom / Eaindra, voice, sounds, language)
- Ctrl+Alt+V                     = talk (press again to send). Speak Burmese or English.
- Ctrl+Alt+Space                 = show / hide
- Chat window: drag the top-left corner to resize,  -  to minimize,  expand button to make it big.
Chat only: Tom and Eaindra talk, answer questions, explain, tell stories and play word games.
They do NOT open programs, make files or do things on the computer. For homework they give hints
and explain step by step, so the children still think for themselves.
Voices need internet (Burmese voice: Nilar for Eaindra, Thiha for Tom).


မြန်မာလို လမ်းညွှန်
---------------------
၁။ ဒီ folder တစ်ခုလုံးကို zip ထဲကနေ ထုတ်ပါ (ဥပမာ C:\Tom-Eaindra)။ zip ထဲကနေ တိုက်ရိုက် မဖွင့်ပါနဲ့။
၂။ Tom-Eaindra.exe ကို နှစ်ချက်နှိပ်ပါ။ "Windows protected your PC" ပေါ်လာရင် "More info" -> "Run anyway" ကိုနှိပ်ပါ။
၃။ ပထမဆုံးအကြိမ်မှာ Settings ပွင့်လာပါမယ်။ https://aistudio.google.com/apikey မှာ အခမဲ့ Gemini key ယူပြီး
    AI providers -> Google Gemini -> Edit -> key ထည့် -> Test -> Save provider -> Save ကိုနှိပ်ပါ။
၄။ ကာတွန်းကို နှိပ်ရင် chat ပွင့်ပါမယ်။ ဆွဲရွှေ့လို့ရပါတယ်။ Right-click (သို့) Ctrl+Alt+S = Settings။
၅။ Ctrl+Alt+V နှိပ်ပြီး မြန်မာလို (သို့) အင်္ဂလိပ်လို ပြောပါ၊ ပြီးရင် ထပ်နှိပ်ပါ။
၆။ Settings -> Character မှာ Tom နဲ့ Eaindra ကို ပြောင်းလို့ရပါတယ်။
၇။ Chat သာ ပြောလို့ရပါတယ် - program ဖွင့်တာ၊ file လုပ်တာ မလုပ်ပါဘူး။ အိမ်စာအတွက် အဖြေ တန်းမပေးဘဲ
    hint ပေးပြီး တစ်ဆင့်ချင်း ရှင်းပြပါတယ်၊ ကလေးတွေ ကိုယ်တိုင် စဉ်းစားရအောင်ပါ။ အသံအတွက် internet လိုပါတယ်။


UPDATES
The app updates itself: about 1.5 minutes after it starts (and every 6 hours) it checks for a newer
version, installs it when you are not busy, and restarts. Settings -> Updates shows the version and
has "Check now". Your settings, AI keys and memories are kept.

For the maker: build with  editions\tom-eaindra\make-portable.ps1  (needs the portable Python folder:
python-3.13 embeddable zip + edge-tts and its packages in Lib\site-packages, python313._pth with
"Lib\site-packages" and "import site").
